# Movimiento sutil del personaje

El fondo `GhostPatchesBackground` del menú de patches ahora tiene un balanceo horizontal suave (±2.5 puntos), un desplazamiento vertical (±2 puntos) y un zoom muy ligero para simular respiración. Se utiliza `TimelineView` y no se animan los botones ni la lista de patches. Si el usuario activa «Reducir movimiento» en Accesibilidad de iOS, el fondo permanece fijo.

Se conserva el resto del proyecto, incluyendo audios, keys y enlace de Telegram. Pendiente de compilación y prueba en un iPhone.
