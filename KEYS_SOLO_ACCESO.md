# Keys únicamente para acceso

- Las keys de Lovable se usan exclusivamente para iniciar sesión y distinguir administrador de usuario.
- La vista de usuario ya no solicita ni muestra patches asignados por key.
- Los usuarios con una key válida ven el mismo paquete incorporado Cuello.3105 y pueden abrirlo en el visor existente.
- El administrador conserva su menú original.
- No se alteran archivos de aplicaciones externas.
- Esta versión no se ha compilado ni probado en iOS.
