# Menú de Patches compartido

- Las keys normales siguen validándose para entrar, pero ya no asignan patches ni consultan un catálogo por key.
- Las keys normales muestran la misma vista original `PatchProjectsView` que usa el administrador para crear, importar, explorar y gestionar paquetes .3105.
- La vista de las keys usa el fondo GhostPatchesBackground y una cabecera Panther IOS con Salir.
- El administrador conserva sus otros menús y su vista original de Patches.
- Se eliminó la vista personalizada anterior, con Head/Neck/Pecho, Aim, catálogo en línea y visor independiente para keys normales.
- El contenido de los proyectos sigue siendo local al dispositivo; no se sincroniza automáticamente entre dispositivos.
- No se ha compilado ni probado en un dispositivo iOS.
