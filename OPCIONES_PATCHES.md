# Opciones del visor de patches

Se añadieron **Apply Patch** y **Restore Originals** para usuarios con keys normales.

- Apply Patch guarda una copia validada del paquete en el directorio privado Documents/PantherWorkspace de Panther iOS.
- Restore Originals elimina esa copia; no altera archivos de otros programas.
- Export .3105 conserva la función de compartir el paquete.
- La lectura del paquete usa PatchPackageCodec. Los botones se deshabilitan cuando no se pudo leer el paquete.

No se ha compilado ni probado en un dispositivo real. No se implementa modificación de Free Fire.
